选品心决技巧 — 项目入口说明
================================

读者打开方式（发给老板 / 新人用这个）
------------------------------------
直接点链接，和读网页一样，无需下载、无需 bat、无需解压：

    https://18ok.github.io/temu-PUD/

微信里长按链接 → 在浏览器打开即可。

分享单篇采访示例：
    https://18ok.github.io/temu-PUD/#read/interview-01

这是什么
--------
独立的 Temu 选品内容站，和 temu-dashboard（选品看板）不是一回事。
现阶段目标：用采访和干货把人留下来，不是推销工具。

开发者本地预览（不要发给读者）
------------------------------
仅自己改稿时用：选品心决技巧\本地预览-仅开发用.bat
需要本机 Python，启动 http://localhost:8765/

源码位置
--------
文件夹：选品心决技巧\
发布目录：docs\（由 GitHub Actions 自动同步发布）

阅读方式
--------
采访、简报、计算器均在首页浮层打开（毛玻璃背景，左侧返回）。
关闭后回到关闭前的滚动位置。

更新内容后
----------
1. 改 选品心决技巧\ 里的文件
2. 双击 同步选品心决到docs.bat（或 push 后 Actions 自动构建）
3. git push master → 自动发布到上方网址

和看板的关系
------------
不捆绑。有流量后读者主动问起工具，再单独介绍 temu-dashboard。
