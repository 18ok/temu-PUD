☁️ 云端同步 vs 协作版 — 组员必读

Temu 选品助手 V10.2.2 · 2026-06-05

很多人问：「不是已经有 ⬆ 同步、📥 团队了吗，为什么还说协作版未开放？」
简短回答：OSS 解决的是「摘要能不能多人互相同步」；协作版要解决的是「多人 PK / 主管看全员」——后者大部分还没做。

一、试用版里已经有什么（✅ 能用）

已有个人 PK

在本机导入 利润统计 .xls + 数据记录 .xlsx → 左侧 🏆 个人 PK → 看 0–100 对齐分。不需要云端。

已有云端摘要同步（需玉成发的 .env）

每人本地 Excel → 系统打成 JSON 摘要（不是原始 Excel） → ⬆ 同步 到 OSS（按「归属人」区分） → 📥 团队 拉同事最新摘要 → 主要用于「团队选品基准」、诊断里个人 vs 团队对比

原始 Excel 不会 整表上传，只传处理后的 JSON 摘要。

二、「协作版未开放」是什么意思（⏳ 还没有）

PK 页上灰色按钮 「团队对比（协作版）」 是故意点不了的。它指的是下面这类能力，当前版本没有：

  • 主管在一个页面看 多个人各自 的对齐分（「谁该辅导」视图）
  • PK 页里的 团队 PK 对比表（不是个人镜子，而是多人并排）
  • 发一个链接，对方 不用导 Excel 就能看团队汇总（未来能力）

未开放这些需要后续版本 + 更完整的数据约定 + 身份校验，试用包不要期待能当考核排名或全员仪表盘用。

三、为什么「有 OSS」还不够？

对比项 现在的 📥 团队 协作版（规划）
拉下来是什么 同事的 选品 SPU 列表，拼成团队基准 每人完整的 对齐分 / 双管线摘要
主要用在哪 诊断、商品画像等「个人 vs 团队基准」 PK 页「团队对比」、主管看谁要帮
PK 页会变吗 不会 — PK 仍只算你自己本机两份 Excel 会 — 多人分数 / 对比视图
身份 归属人自己填名字（试用够用） 需邀请码 / 团队 ID（防乱填、防蹭席位）
技术原因（给好奇的同事）： 个人 PK 用的是本机完整店铺字段（如 ctr、cvr 等）；云端摘要里的店铺字段较少，且 📥 团队目前只合并选品侧，不够在云端直接算每个人的 PK。所以：同事都同步了，你的 PK 页仍然只是你自己的分——这是设计如此，不是 bug。

四、试用时你可以 / 不可以做什么

可以 ✅不可以 ❌
  • 本地双 Excel → 看个人 PK
  • 有 .env 时 ⬆ 同步、📥 拉团队基准
  • 在诊断页看个人 vs 团队 SPU 对比
  • 复制 PK 链接（对方需自己导入 Excel）
  • 在 PK 页看全队排名 / 多人对比
  • 认为同步了就能看所有人的 PK 分
  • 把 PK 当考核淘汰依据（定位是辅导镜子）
  • 期待灰色「协作版」按钮能点

五、和「使用限制」的关系

压缩包里的 组员使用说明.html §七 写了完整使用限制。和本文相关的核心一句：

PK = 个人对齐分，不是团队排名。 协作版尚未开放；云端同步 ≠ 协作版已上线。

六、有问题找谁

  • 打不开 / CORS → 必须用 启动本地看板.bat
  • PK 空白 → 两份 Excel 都要导入
  • 同步失败 → 找玉成要 .env 或暂只用本地 PK
  • 功能建议（要不要协作版、要不要手机版）→ 反馈给玉成，正在 14 天试用收集意见
