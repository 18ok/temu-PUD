📊 商品画像 — 聚类分析

基于 K-Means 聚类算法，按克重、成本、毛利率、日销量对商品自动分组，快速识别好品与差品的特征分布。

ℹ📂 暂无数据，请先前往「数据导入」页面上传 Excel 文件。

📋 选品规则 — 从数据中提取铁律

基于聚类分组结果，用纯统计方法自动提取可操作的选品规则。每条规则包含条件、验证指标和置信度，选品时优先匹配 🟢 铁律，遇到 🔴 避坑特征直接 pass。

ℹ📂 暂无数据，请先前往「数据导入」页面上传 Excel 文件。

🔮 智能预测 — 利润推算

输入新品的成本、克重和预计卖价，系统自动匹对历史相似品数据，给出毛利率与日销预估、风险评级和选品建议。

ℹ📂 暂无数据，请先前往「数据导入」页面上传 Excel 文件。

🚫 避坑清单 — 亏损品异常检测

自动筛选历史亏损品，按特征分组分析亏损原因，提炼可操作的避坑规则，避免重复踩坑。

ℹ📂 暂无数据，请先前往「数据导入」页面上传 Excel 文件。

📈 个人诊断

对比历史快照，追踪选品质量变化；可导出 Markdown 周报供复盘。
