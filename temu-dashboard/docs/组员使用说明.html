二、试用核心：个人 PK（不需要云端）

第一次试用建议只做下面几步，不必配置 OSS：

①
左侧点 数据导入
②
拖入 店铺利润统计 .xls
③
再拖入 店铺数据记录 .xlsx（两份都导入才能看 PK）
④
左侧点 🏆 个人 PK — 查看 0–100 对齐分与建议
页顶说明：「这是你个人的选品×运营对齐分」 — 不是团队排名。
灰色按钮「团队对比（协作版）」尚未开放，敬请期待。
⑤
（可选）PK 页点 复制分享链接 — 对方打开后需自己导入 Excel，看不到你的数据

三、可选：团队云端同步（OSS）

数据摘要存在阿里云 OSS。网页版与 bat 均可同步，Key 由玉成私聊，勿发群。

网页版（同事常用）

1
打开 https://18ok.github.io/temu-PUD/
2
侧边栏 ⚙ OSS → 填归属人 + 玉成发的 AccessKey → 保存
3
导入 Excel 后 ⬆ 同步；看别人 📥 团队

本地 bat（管理员 · .env 托管）

1
把玉成发的 .env 放到与 bat 同一文件夹
2
关闭 bat 窗口后重新双击 启动本地看板.bat
3
左侧 ⚙ OSS 配置 → 只填 归属人（你自己的名字，每人不同）→ 保存
4
导入 Excel 后点 ⬆ 同步；需要看别人时点 📥 团队
⚠ 不要把 .env、AccessKey 发到微信群。 原始 Excel 不会上传云端，只上传处理后的 JSON 摘要。

若暂时没有 .env：可只用本地 PK / 诊断，不影响试用。

四、各页面速查

页面用途
数据导入上传 Excel；内部阶段验证默认隐藏，不作为组员操作流程
🏆 个人 PK试用重点 — 对齐分 + 差距说明
商品画像商品经营诊断；聚类只做初筛，最终要结合归因字段
个人诊断趋势与快照；≥2 份快照可导出周报
店铺运营店铺数据记录明细

五、常见错误

现象原因解决
CORS / 网络拦截 用了本地 HTML 或错误打开方式 改用 https://18ok.github.io/temu-PUD/；无网再找玉成要 bat
PK 页空白 / 提示去导入 缺 profit 或 store 一侧 Excel 数据导入页两份都拖入
分享链接打开没分数 链接不含 Excel，设计如此 对方在自己电脑导入两份表后再看 PK
同步失败 无 .env 或归属人未填 找玉成要 .env；或暂不同步，只用本地 PK
云端只有你自己 同事尚未同步 等同事同步或先忽略团队功能

六、试用反馈（帮玉成改进）

  • 30 秒内能不能理解 PK 分数在说什么？
  • 更常用电脑还是手机？
  • 愿意每周上传 Excel 看一次分吗？
  • 有问题直接微信找玉成，或导入页复制「验证摘要」发给他

七、使用限制（试用必读）

本包为内部试用版，请勿转发压缩包或 Key 给团队外人员。
限制项说明
适用范围 内部同事试用；非对外产品、非公开下载
运行环境 现代浏览器即可（Chrome / Edge 推荐）；网页版不用 Python；bat 仅备选
数据格式 仅支持指定两份 Excel：利润统计 .xls + 数据记录 .xlsx；表头需与团队现用模板一致
PK 分数 仅本人两份表的对齐分；不是团队排名、不是考核淘汰依据
协作版 「团队对比（协作版）」尚未开放；主管不能通过本版一眼看全员 — 详见 OSS与协作版说明.html
分享链接 #pk 链接不含 Excel；对方须在自己电脑导入数据后才能看分
云端同步 可选；无 .env 时仅本地使用。同步只传 JSON 摘要，不传原始 Excel
数据与保密 公司利润/店铺/客户信息不得发群、发 AI、上传公开网盘；试用完毕可清除浏览器本地数据
稳定性 试用版界面仍在加固；请勿依赖为唯一生产工具，Excel 原件请自行备份

定位：个人辅导 / 自我对照用的镜子，不是人事考核系统。试用问题与反馈统一找玉成。

八、安全提醒

  • 试用数据留在本机浏览器；勿在公共电脑留 Key
  • 每人用自己的名字当「归属人」
  • 不要把真实利润表发到群聊或 AI 对话
