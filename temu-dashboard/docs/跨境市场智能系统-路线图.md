# 跨境市场智能系统 · 路线规划

> 从 Temu 选品工具 → 跨境市场商业智能平台
> 2026-06 草稿 · 待迭代

---

## 一、核心愿景

一张截图输入，系统输出：

1. **这个品好不好**——市场位置、竞争格局、利润空间
2. **依据这个品推算更多爆款**——基于公司能力池，该品类下还有什么能打
3. **类目市场潮汐**——这个品类在生命周期哪个阶段，下一个浪在哪

最终覆盖 **Temu → Amazon → 独立站 → 外贸B2B** 全渠道。

---

## 二、系统架构总览

```
+-- 前端展示层 (基于现有看板) ----------------+
| 截图输入 | 市场地图 | 爆款看板 | 潮汐仪表盘 |
+-- AI 推理层 (核心大脑) ---------------------+
| Vision Parser | 爆款推算引擎 | 潮汐模型     |
| 能力匹配引擎 (市场机会 x 公司能力)          |
+-- 市场数据湖 ------------------------------+
| Temu爬虫 | Amazon爬虫 | Shein/1688爬虫     |
| 历史快照库 | 价格时序 | 评论/评分          |
+-- 数据基础设施 ----------------------------+
| 商品画像库 | 企业能力档案 | 时序数据库      |
+--------------------------------------------+
```

## 三、分期路线图

### Phase 1 — 截图 → 竞品分析（MVP）

目标：一张截图给结果先跑通

| 模块 | 做什么 | 产出 |
|------|--------|------|
| 截图输入 | 看板新增截图页，手动录入品类/定价/卖点 | 商品快照卡片 |
| Temu 爬虫 | Playwright 搜同类品 -> 价格/销量/评分分布 | 竞品对比表 |
| 竞品看板 | 展示"这个品在市场上什么位置" | 价格带分布图 + 竞争格局 |

技术决策：
- Vision 识别先用手动标签替代，Phase 3 再上
- 存储先用 JSON 文件放本地
- 爬虫从 Temu 开始

预估工期：2-3 周

产出物示例：
```
输入：一张 Temu 手机壳截图
输出：
  > 同品类竞品价格分布（$1.99 - $9.99）
  > 你的品在价格带位置（中低位）
  > 同款销量估算对比
  > 建议定价区间
```

---

### Phase 2 — 市场数据网络

目标：从单平台到多平台，从一次性到持续积累

| 模块 | 做什么 | 产出 |
|------|--------|------|
| 多平台爬虫 | Temu + Amazon + 1688/AliExpress | 跨平台比价 |
| 定时爬取 | 每日自动刷新关键词/品类数据 | 历史积累 |
| 服务端存储 | SQLite/PostgreSQL | 结构化商品库 |
| 企业能力档案 | 录入公司擅长的品类、成本结构、产能 | 能力画像 |

技术决策：
- 后端用 Python FastAPI + SQLite 起步
- 爬虫调度用 APScheduler
- 企业能力档案第一次由手动录入

预估工期：3-4 周

---

### Phase 3 — AI 推理引擎

目标：系统开始"自己思考"——看图识品、推算爆款

| 模块 | 做什么 | 产出 |
|------|--------|------|
| Vision 识别 | 截图->品类/风格/颜色/材质/卖点标签 | 自动结构化商品 |
| 爆款推算引擎 | 基于竞品数据 + 历史爆款特征的评分模型 | 爆款概率评分 |
| 能力匹配 | 市场机会 x 公司能力 -> 可做/慎做/不做 | 执行建议 |
| 价格空白带 | 发现竞品没覆盖到的价格/规格空间 | 新品切入建议 |

技术决策：
- Vision 用 Claude/OpenAI API
- 爆款评分先用规则引擎 + 统计模型
- 能力匹配规则由你定义

预估工期：4-6 周

---

### Phase 4 — 类目潮汐模型

目标：预判——这个类目还能火多久？下一波在哪？

| 模块 | 做什么 | 产出 |
|------|--------|------|
| 生命周期识别 | 基于搜索量/新品增速/价格走势判断阶段 | 萌芽/增长/高峰/衰退 |
| 季节性模型 | 历史数据 + 趋势线 | 下个旺季/淡季时间点 |
| 趋势预警 | 异常信号自动提醒 | 早于市场的反应时间 |
| 跨平台交叉验证 | Temu vs Amazon vs Google Trends | 真实需求判断 |

技术决策：
- 潮汐模型需要 Phase 2 积累 2-3 个月数据
- 初期用经验规则，数据够了上时序模型

预估工期：6-8 周

---

### Phase 5 — 平台化 / 外贸延伸

目标：从选品工具 -> 跨境商业决策平台

| 模块 | 做什么 |
|------|--------|
| 外贸 B2B 接入 | 1688 采购端 + 国际站需求信号 |
| 多店铺管理 | 不同店铺/团队的数据隔离与对比 |
| 定制报告 | 一键生成类目分析报告 |
| API 开放 | 给自己的其他工具调用 |

---

## 四、关键设计原则

1. Phase 1 先跑通闭环：截图 -> 爬虫 -> 看板，哪怕 Vision 用手动标签。先让"一张图给结果"这个链路跑起来。
2. 能力匹配是核心竞争力：别人的爆款不一定是你的爆款。系统真正的价值在于"基于你的供应链能力，这个品类里什么你能打"。
3. 数据资产越滚越值钱：Phase 2 积累的市场数据 + Phase 4 的潮汐信号，爬 3 个月后就是你们团队独有的数据壁垒。
4. 不做纯技术堆砌：每个阶段都有实际产出。
