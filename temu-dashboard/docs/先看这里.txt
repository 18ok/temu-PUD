3. 右上角「通知」小窗看上传结果（多条可滚轮查看）

── 使用限制（必读）──
· 内部试用，勿把 Key 发给团队外的人
· 优先用网页链接；不要直接双击 HTML 文件
· 对齐分是团队协作体系下的个人成长镜子，不是考核淘汰依据
· 团队协作是主线：对齐分、团队基准、后续主管看板一起推进
· 当前阶段先跑对齐分 + 摘要同步；完整团队登录 / 主管看板按部署节奏开放
· 分享链接不含 Excel，对方需自己导入
· 公司数据勿发群 / 勿发 AI；Excel 原件请自行备份

── 可选：团队云端同步 ──
⚙ 管理后台 → 同步配置 → 填归属人 + 玉成私聊的 Key
→ ⬆ 同步团队 / 📥 团队基准
（V10.4 起同步入口在管理后台，不在侧栏单独放 OSS 按钮）
这是团队协作的第一阶段：先同步摘要和团队基准，再扩到登录、分组和主管看板。
不要把 Key 发到群里。

需玉成单独发 .env 文件。
