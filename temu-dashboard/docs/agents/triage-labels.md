# Triage Labels

Skills 使用五个 canonical triage roles。这个文件把这些 roles 映射到此 repo GitHub Issues 中实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `待评估`              | 需要评估这个 issue |
| `needs-info`               | `待补充`              | 等待补充更多信息 |
| `ready-for-agent`          | `AI可做`              | 已完整说明，AI 可接手 |
| `ready-for-human`          | `人工做`              | 需要人工实现 |
| `wontfix`                  | `不做`                | 不会处理 |

当某个 skill 提到 role（例如 "apply the AFK-ready triage label"）时，使用此表中对应的 label 字符串。
