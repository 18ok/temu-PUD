# 希音商品属性库 V1 使用说明

## 打开方式

优先直接打开：

```text
shein-assistant/index.html
```

如果浏览器限制 IndexedDB 或复制功能，用项目目录启动本地服务：

```powershell
cd "C:\Users\an'kang\Desktop\POD智能定制\temu-dashboard\shein-assistant"
python -m http.server 8091
```

然后访问：

```text
http://localhost:8091/
```

## 使用流程

1. 点击「选择 xlsx」，导入 `希音表格模板.xlsx`。
2. 搜索中文类目、规格值、货号、SKU、SPU、SKC、英文标题、属性名或属性值。
3. 在商品档案里复制核心信息或缺失项。
4. 在待补清单里复制整批待补项。

数据保存在浏览器 IndexedDB：`shein_attribute_library_v1`。再次打开页面会自动恢复上次导入的属性库。
