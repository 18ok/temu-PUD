二、试用核心：团队对齐分（不需要云端）

第一次试用建议只做下面几步，不必配置 OSS：

①
左侧点 📥 团队工作台
②
拖入 店铺利润统计 .xls
③
再拖入 店铺数据记录 .xlsx（两份都导入才能看对齐分）
④
左侧点 🏆 团队对齐分 — 查看 0–100 对齐分与建议
页顶说明：「团队协作下的个人成长分」 — 它是团队体系里的个人镜子，不是考核排名。
现阶段先看对齐分与团队基准；注册、分组和主管看板按服务端部署节奏逐步开放。
⑤
（可选）对齐分页点 复制分享链接 — 对方打开后需自己导入 Excel，看不到你的数据

三、可选：团队云端同步（OSS）

数据摘要存在阿里云 OSS。网页版与 bat 均可同步，Key 由玉成私聊，勿发群。

V10.4 起，同步相关操作集中在侧栏底部或顶栏的 ⚙ 管理后台（不再在侧栏单独放 OSS 按钮）。
⬆ 同步团队 / 📥 团队基准 是团队协作第一阶段，主要用于个人诊断里的团队基准。
完整协作会在此基础上继续扩展到团队登录、分组和主管团队看板。

网页版（同事常用）

1
打开 https://18ok.github.io/temu-PUD/
2
进入 ⚙ 管理后台 → ⚙ 同步配置 → 填归属人 + 玉成发的 AccessKey → 保存
3
在团队工作台导入 Excel 后，管理后台点 ⬆ 同步团队；看别人 📥 团队基准

本地 bat（管理员 · .env 托管）

1
把玉成发的 .env 放到与 bat 同一文件夹
2
关闭 bat 窗口后重新双击 启动本地看板.bat
3
⚙ 管理后台 → ⚙ 同步配置 → 只填 归属人（你自己的名字，每人不同）→ 保存
4
导入 Excel 后点 ⬆ 同步团队；需要看别人时点 📥 团队基准
本地 bat 模式下，管理后台还可看到后端服务状态、同步记录与团队登录入口（协作 API 骨架）。
网页版 GitHub Pages 以 OSS 摘要同步为主；团队账号登录随 ECS 部署节奏开放。
⚠ 不要把 .env、AccessKey 发到微信群。 原始 Excel 不会上传云端，只上传处理后的 JSON 摘要。

若暂时没有 Key：可只用本地对齐分 / 诊断，不影响试用。

五、常见错误

现象原因解决
CORS / 网络拦截 用了本地 HTML 或错误打开方式 优先改用 https://18ok.github.io/temu-PUD/；无网再找玉成要 bat
找不到 ⚙ OSS 按钮 V10.4 已迁入管理后台 侧栏底部或顶栏点 ⚙ 管理后台 → 同步配置 / 同步团队
对齐分页空白 / 提示去导入 缺 profit 或 store 一侧 Excel 团队工作台两份都拖入
分享链接打开没分数 链接不含 Excel，设计如此 对方在自己电脑导入两份表后再看对齐分
同步失败 Key 未填或归属人未填 管理后台 → 同步配置；或找玉成要 Key；暂不同步也可只用本地
云端只有你自己 同事尚未同步 等同事同步或先忽略团队功能
团队登录点不了 网页版协作 API 未部署 先用 OSS 摘要同步；完整登录需本地 bat 或后续 ECS 部署

七、使用限制（试用必读）

本包为内部试用版，请勿转发压缩包或 Key 给团队外人员。
限制项说明
适用范围 内部同事试用；非对外产品、非公开下载
运行环境 现代浏览器即可（Chrome / Edge 推荐）；网页版不用 Python；bat 仅备选
数据格式 仅支持指定两份 Excel：利润统计 .xls + 数据记录 .xlsx；表头需与团队现用模板一致
对齐分 本人两份表的对齐分，放在团队基准里看改进方向；不是考核淘汰依据
协作版 团队协作是主线，当前先开放摘要同步和团队基准；团队登录 / 邀请码 / 主管团队看板按部署节奏逐步开放 — 详见 OSS与协作版说明.html
分享链接 #pk 链接不含 Excel；对方须在自己电脑导入数据后才能看分
云端同步 可选；无 Key 时仅本地使用。同步只传 JSON 摘要，不传原始 Excel
数据与保密 公司利润/店铺/客户信息不得发群、发 AI、上传公开网盘；试用完毕可在管理后台清除本地业务数据
稳定性 试用版界面仍在加固；请勿依赖为唯一生产工具，Excel 原件请自行备份

定位：个人辅导 / 自我对照用的镜子，不是人事考核系统。试用问题与反馈统一找玉成。

八、安全提醒

  • 试用数据留在本机浏览器；勿在公共电脑留 Key
  • 每人用自己的名字当「归属人」
  • 不要把真实利润表发到群聊或 AI 对话
