📊 数据库设计 (PostgreSQL)

核心表结构

users — 用户表（邮箱、角色、部门、状态）
generations — 生成记录（类型、模型、prompt、结果JSON、成本）
cost_stats — 成本统计（按用户+日期+模型汇总）
system_config — 系统配置（后期用）
audit_logs — 审计日志（操作人、IP、时间、操作类型）

索引策略

CREATE INDEX idx_generations_user_id
  ON generations(user_id);
CREATE INDEX idx_generations_created_at
  ON generations(created_at DESC);
CREATE INDEX idx_generations_type
  ON generations(type);
CREATE INDEX idx_cost_stats_user_date
  ON cost_stats(user_id, date DESC);
CREATE INDEX idx_audit_logs_user_id
  ON audit_logs(user_id);
CREATE INDEX idx_audit_logs_created_at
  ON audit_logs(created_at DESC);

关键设计决策

JSONB 存AI结果
标题数组/图片URL数组，灵活扩展
成本精确到小数点后6位
DECIMAL(10,6)，美元计价
预留 audit_logs
后期合规审计，表结构已就绪

🚀 今天就可以开始

# 第1步：创建项目（2小时搞定）
# 1. 创建 Next.js 项目（10分钟）
npx create-next-app@latest pod-ai-platform --typescript --tailwind --app
cd pod-ai-platform

# 2. 安装核心依赖（5分钟）
npm install \
  openai \
  @anthropic-ai/sdk \
  @google/generative-ai \
  replicate \
  next-auth @auth/prisma-adapter \
  prisma @prisma/client \
  ioredis minio \
  zod zustand @tanstack/react-query \
  date-fns recharts

# 3. 初始化数据库 ORM（5分钟）
npx prisma init

# 4. 配置环境变量（10分钟）
cp .env.example .env.local
# 编辑 .env.local，填入 API 密钥

# 5. 启动！（1分钟）
npm run dev
